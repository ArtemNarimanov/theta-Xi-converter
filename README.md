# Конвертер данных плоского ребра θ(ξ)

Портативное GUI-приложение (tkinter) для нормализации данных теплового расчёта
плоского ребра, полученных из `.dat`-файлов GraphLab, в безразмерные координаты:

```
ξ = x / L
θ = (T − T1) / (T0 − T1)
```

По полученным файлам `xi.dat` и `theta.dat` можно построить график θ(ξ).
Приложение не решает задачу теплопроводности — только нормализует входные данные.

## Требования

- Windows, Python 3.9+ (tkinter входит в стандартную библиотеку);
- только стандартная библиотека: numpy/pandas/matplotlib/PySide **не используются**;
- всё приложение — один файл `fin_theta_converter.py`;
- работает офлайн, без установки и админских прав.

## Запуск

1. **Без сборки:** переименуйте `fin_theta_converter.py` в `fin_theta_converter.pyw`
   и запустите двойным кликом (окно без консоли), либо:

   ```bat
   python fin_theta_converter.py
   ```

2. **Портативный .exe** (сборка через PyInstaller, не входит в репозиторий):

   ```bat
   pip install pyinstaller
   pyinstaller --onefile --windowed --name fin_theta_converter --clean --noconfirm fin_theta_converter.py
   ```

   Готовый `fin_theta_converter.exe` появится в `dist/`.

## Входные данные

Раздельные файлы, каждый со **своей независимой стартовой строкой данных**:

- файл с `x` (координата, м) — данные с 1-й строки (дефолт `строка начала = 1`);
- файл с `T` (температура, К) — в файлах GraphLab данные начинаются со 4-й строки
  (заголовок + нулевой ряд), поэтому дефолт для T — `строка начала = 4`.

Поддерживаются: разделители пробел/табуляция/`,`/`;`, пустые строки, комментарии
`#`, `%`, `//`, нечисловые заголовки, научный формат чисел, лишние колонки.

Параметры расчёта:

- `L` — высота охлаждаемой части, м (дефолт 0.060);
- `T0`, `T1` — вводят **в градусах Цельсия** (дефолты 120.0 и 20.0), справа
  отображается значение в К по формуле `T = t + 273.15`.

## Выходные данные

Числовой формат повторяет входные файлы (без заголовков и служебных рядов):

- **ξ** — одна строка, значения через `;` с завершающим `;`, формат `%.4f`
  (как в `x.dat`): `0.0250;0.0750;...;0.9750;`
- **θ** — по 16 значений в строке, формат `%.4E` (как в `result_tav.dat`):
  `9.8960E-01  9.5150E-01  ...`

Имя файла θ предлагается автоматически по имени файла с T:
`result_tav.dat` → `result_theta_tav.dat`. Ручное имя не затирается.
Если в поле имени указан абсолютный путь — он используется как есть.

## Примеры данных

Входные файлы для проверки лежат в папке `in/`:

| файл | назначение |
|---|---|
| `in/x.dat` | координата x, 20 значений, одна строка через `;` |
| `in/result_tav.dat` | температура T (GraphLab), данные со 2-го ряда чисел (строка 4) |
| `in/result_tw1.dat`, `in/result_tw2.dat` | дополнительные файлы температуры |

Пример запуска на них: `in/x.dat` + `in/result_tav.dat`, стартовая строка T = 4 →
20 пар значений, ξ[0] = 0.0250, θ[0] ≈ 0.9896.
